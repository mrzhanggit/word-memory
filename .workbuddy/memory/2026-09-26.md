## 发音跨设备不一致诊断（代码级根因）
- 症状：同一单词在不同设备播放，iPhone/Mac 清晰，部分 Android 含糊到听不出。
- 定位：`src/hooks/useProgress.ts:219` 的 `speak()` —— 全项目**唯一的发音实现**，调用点 8 处（FamilyDetail 3 / Study 1 / Quiz 4）。
  ```ts
  export function speak(text: string) {
    const u = new SpeechSynthesisUtterance(text);
    u.lang = 'en-US';        // 只给语言，未指定 voice
    u.rate = 0.85;
    speechSynthesis.cancel();  // 紧接 speak，部分引擎会吞掉开头
    speechSynthesis.speak(u);
  }
  ```
- **核心结论：发音数据不在本项目服务器上**。Web Speech API 是"转交操作系统 TTS 引擎"的代理，音质由**设备本地引擎**决定，所以跨设备不一致是必然结果，不是 bug。
- 五处代码缺陷：① 未指定 `voice`（浏览器自行挑选，各设备不同）② 未处理 `getVoices()` 异步为空（首次调用常返回 []，需监听 `voiceschanged`）③ `cancel()` 紧接 `speak()` 导致吞音 ④ **零音频资产兜底**（`public/` 只有 scenes 插图，无任何 mp3/wav）⑤ `FamilyWord` 类型无音标/音频字段。
- 设备引擎对照：iOS/macOS→Apple 系统语音（清晰）；Android Chrome 联网且装英文包→Google 云端（可用）；**Android 离线 / 国产 ROM / 微信 X5 内核→本地共振峰合成或回退到中文语音读英文**（即"含糊听不出"的典型成因）。
- 词条实测：去重英文单词 **765 个**（不含重复条目）。
- **音源实测（2026-09-26）**：`https://dict.youdao.com/dictvoice?audio=<word>&type=2`（美音，type=1 英音）返回 200 + `audio/mpeg`，MP3 64kbps 48kHz 单声道，约 10KB/条 → **765 条合计约 8MB**。而 `api.dictionaryapi.dev` 本次请求返回空，不可靠。
- 改进优先级：**P0 治标**（显式选 voice + voiceschanged + 修 cancel + 无英文语音时提示）成本近零但无法保证一致；**P1 治本**（765 条音频一次性预生成 → 存 Supabase Storage，他已有该基础设施与上传脚本范式）→ 所有设备听到完全一致；P2 长期（音节分解朗读、语速/音色设置、离线缓存）。
- 判断依据：只要音频来源仍是设备，「跨设备一致」在原理上无法达成。

## 有道词典数据接入可行性实测（全部接口实测于 2026-09-26）
张总喜欢有道网页版（youdao.com/result?word=happy）的发音、释义、例句、原声，希望接进项目。实测全部端点（**注意：全部需 `--noproxy '*'` 直连，走 7892 代理不通**）：

| 端点 | 带 `Origin` 头 | 可前端直用 |
|---|---|---|
| `dict.youdao.com/jsonapi?q=<word>` | **403 防盗链** | ❌ 必须构建时/服务端抓取 |
| `dict.youdao.com/dictvoice?audio=<word>&type=2`（美音，type=1 英音） | 200 `audio/mpeg` | ✅ 可跨域播放 |
| `dict.youdao.com/pureaudio?docid=<id>`（原声例句音频） | 200 `audio/mp3` | ✅ |
| `dict.youdao.com/purevideo?docid=<id>&auto=true`（原声视频） | 200 **`video/x-flv`** | ⚠️ **FLV 浏览器不支持播放** |
| `dict.youdao.com/pureimage?docid=<id>`（视频封面帧） | 200 `image/jpeg` | ✅ |

- **抓取性能**：`jsonapi` 无 Origin 头时 80–135ms/词、200 OK、体积 35–107KB/词 → 765 词全程约 2 分钟。
- **数据字段**：`ec.word[0]` 含 `usphone`/`ukphone`（IPA 音标，如 `ˈhæpi`）+ `usspeech`/`ukspeech`（发音参数）+ `trs`（中文释义）；`blng_sents_part.sentence-pair` 双语例句（含 `sentence-translation`）；`auth_sents_part.sent` 权威例句（FORBES 等来源，`speech` 字段可拼朗读 URL）；`media_sents_part.sent` / `video_sents` 原声例句（`streamUrl` + `source` 如 VOA、耶鲁公开课）。
- `blng_sents_part` 共 3 条、`auth_sents_part` 共 3 条（单次返回量有限）。
- ⚠️ **版权分层**：jsonapi 同时含 `oxford`/`collins`/`webster`（版权词典，**公开分发有风险，建议不取**）；`ec.source.name = 有道词典`（自有内容，风险较低）；音标属事实数据；原声例句来自 VOA/公开课/影视，权利状态不一。建议个人自用 + 标注来源，不公开分发词典正文。
- **推荐管线**：构建时一次性抓取 → 裁剪（音标+`ec`释义+例句+原声 URL）→ `dict.json` 约 1.5MB 随包发布；单词音频下载自持（美音+英音约 8–15MB）→ Supabase Storage；例句/原声音频**直接引用有道 URL 按需播放**（全量下载约 70MB，不划算）。
- 该管线可与前述「发音 P1 治本」合并实施：自持音频同时解决跨设备一致性。
