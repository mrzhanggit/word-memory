## git 状态整理与推送排障
- 提交词族导航改进 + Supabase Storage 迁移（commit 6351bc9，392 文件）。
- main 与 origin/main 曾分叉（远程多了网页端加的 README commit d41eea4），`git pull --rebase` 解开。
- 推送失败三层根因（依次排查）：
  1. **环境变量代理失效**：会话 env 里 `HTTP(S)_PROXY=127.0.0.1:49286`（WorkBuddy 动态端口）已死 → CONNECT 502。GitHub 直连可用（`curl --noproxy '*'` 200），用 `env -u HTTP_PROXY -u HTTPS_PROXY -u http_proxy -u https_proxy` 绕过。
  2. **remote URL 内嵌失效旧 token**（ghp_Mde...）：git 优先用 URL 内嵌凭据，credential helper 根本不生效 → "Invalid username or token"。修复：`git remote set-url origin https://github.com/mrzhanggit/word-memory.git`。
  3. **~/.gitconfig.lock 残留**（9 月 8 日留下）导致 `gh auth setup-git` 失败。删除 lock 后配置成功，git 现在用 gh 的 keyring token 做凭据（credential.https://github.com.helper = !gh auth git-credential）。
- 最终推送命令模式：`env -u HTTP_PROXY ... git -c credential.helper= -c "credential.helper=!/opt/homebrew/bin/gh auth git-credential" push`（重置 helper 链只用 gh）。
- ⚠️ 旧 PAT（ghp_Mde...）已在失效状态，建议用户去 GitHub Settings 检查删除。
- 推送量 132MB：git 历史里 dist/ 等旧产物 blob 较多，后续可考虑 .gitignore 排除 dist-*（未做，等用户确认）。
