## 本地运行单词应用（端口冲突处理）
- 用户要在 Mac 本地运行「图像记忆单词」应用，并关心合盖后手机能否连接。
- 启动 `npm run dev -- --host 0.0.0.0`，但 **5173 端口被另一个 Vite 项目占用**（公卫系统，路径 `/Users/zhangchengbin/Downloads/公卫系统项目/04-本地应用/frontend/`，进程 PID 65553，8:38AM 起）。
- 解决：杀掉被挤压的单词 app 旧进程，改用 **5188 端口** 重新启动：`npm run dev -- --host 0.0.0.0 --port 5188`，日志 `/tmp/dev-wordmem.log`。验证标题「图像英文记忆法 · 背单词」、HTTP 200。
- 为支持合盖后手机访问：后台起 `caffeinate -s` 阻止系统睡眠（进程 95760）；当前 Mac 接电源(AC Power)，合盖后 WiFi 保持，手机可访问 `http://192.168.1.105:5188/`。
- 教训：本机同时跑多个 Vite 项目时，默认 5173 会冲突，启动前应 `lsof -iTCP:5173 -sTCP:LISTEN` 检查，或直接指定冷门端口（如 5188）。
- 提醒用户：本地运行依赖 Mac 不睡眠+接电源；若只想要"合盖也能手机学"，云端方案(GitHub Pages 网站 + 飞书多维表格)更省心，完全不依赖 Mac 状态。
